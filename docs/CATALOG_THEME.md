# 图鉴界面材质

图鉴使用一张逐像素绘制的专用图集，不覆盖 Minecraft 全局按钮材质。

## 设计

- 深灰钢底色、黑色描边、1px 高光与阴影斜面，金色只用于选中、焦点和强调信息。
- 边框按 1:1 像素绘制，九宫格只拉伸纯色中心，任何 GUI 缩放下边缘都清晰。
- 布局：顶部标题栏（标题、当前页面、关闭按钮）；左侧页签（图标、名称、条目数），底部为“部件属性 / 获取途径”按钮；右侧工具栏（内嵌放大镜的搜索框、筛选、排序、升降序）；状态行（结果数、可点击移除的已选筛选标签）；列表区（斑马纹行、物品槽、悬停及固定详情高亮）。
- 弹层：分类改为下划线页签，选项使用绘制的勾选框 / 单选框，高度随选项数量变化。

## 资源

- 路径：`assets/tinkers_construct_filter/textures/gui/catalog_atlas.png`，256 × 256，RGBA。
- 精灵坐标集中在 `CatalogSkin` 的 `Sprite` 常量中（u、v、宽、高、九宫格边框）。资源包替换时需保持相同布局；更高分辨率的同布局图片也可用，UV 按 256 归一化。
- 关闭纹理模糊，使用边缘限制。

| 区域 | 内容 |
|---|---|
| y 0–31 | 主窗口（32×32，边框 6）、侧栏、标题栏、弹层、列表井、筛选标签及悬停 |
| y 32–47 | 普通、悬停、选中、禁用按钮；页签悬停、页签选中 |
| y 48–65 | 列表行、交替行、悬停行、固定行；物品槽、物品槽悬停（18×18） |
| y 64–79 | 输入框、聚焦输入框、滚动轨道、滑块、滑块悬停 |
| y 96–111 | 16×16 图标：材料锭、部件镐头、强化宝石、词条书、锤子 |
| y 112–120 | 9×9 白色可着色图标：搜索、筛选、排序、升序、降序、星、关闭、历史、移除 |
| y 121–129 | 9×9 彩色勾选框、已勾选、单选框、已选单选框 |

## 绘制来源

图集由脚本逐像素绘制（ASCII 像素画与几何描边），不使用图像生成或第三方材质。白色小图标在运行时通过着色器颜色着色，用于悬停、选中及禁用状态。

## 检查

1. 四个页面、筛选、排序、部件属性、搜索历史弹层的材质完整。
2. 切换 GUI 缩放 1–4，检查边框、短按钮、长标题。
3. 鼠标位于弹层覆盖区域时，底层条目不得高亮、弹出提示或响应点击。
4. 点击固定详情并滚动，检查物品、数量、下划线词条二级提示的层级。
5. 点击搜索框留白与放大镜可聚焦，输入、选择文字时光标位置正确。
6. 点击状态行的筛选标签可移除对应条件。
