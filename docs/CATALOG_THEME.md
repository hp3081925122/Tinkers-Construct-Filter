# 图鉴界面材质与三栏工作台设计

图鉴界面采用逐像素绘制的「匠魂焦黑熔炉风」专用图集，不覆盖或修改原版全局界面材质。

## 视觉与布局特性

- **材质语言**：焦黑砖石与暖炭铸铁底板、1px 金属倒角明暗斜面、四角锻铜铆钉包角，熔金高亮仅用于当前激活项、焦点框、锁定指示与核心数值。
- **零拉伸伪影九宫格**：所有铆钉、包角与切角均限定在 `border × border` 角块内，四边拉伸带与中心区域保持纯净色阶；相邻精灵之间至少留出 2px 透明间距，消除不同缩放比例下的 UV 采样渗色。
- **自适应三栏工作台分屏**：
  - 左栏：四页导航页签（材料、部件、强化、词条，带独立凹槽数量角标）与底部“部件属性 / 获取途径”设置入口。
  - 中栏：紧凑双行列表（行首 18×18 焦黑物品槽悬停看原生物品提示，主行名称与等级/排序值对齐，次行展示词条、部件类型或分类摘要）。
  - 右栏：常驻详情检查器面板（顶部固定主物品锻铜底座、等级徽章、制作方式/分类副标题与可点击切换的固定图钉按钮；下方为可滚动的石板分区卡片、点线对齐属性表、可悬停词条铭牌胶囊与 18×18 配方/来源物品网格；极窄窗口下自动回退为浮动详情窗）。
- **匠魂工坊入口**：在 `TinkerStationScreen` 注入 22×22 锻铜包角铁砧图标按钮，并通过 `getModuleAreas` 向 JEI 声明避让区域。
